# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

# Day 10 - Facility Management Dashboard

## Project Description
Facility Management Dashboard is a web application used to monitor facilities and manage complaints in places such as computer labs, libraries, and classrooms.

## Features
- View all registered facilities.
- Check facility status.
- View total facilities and complaints.
- Add new complaints with title and location.
- View recent complaints.
- Fetch data from the backend API.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Node.js
- Express.js
- REST API

## Facilities
- Computer Lab
- Library
- Classroom A

## How to Run the Project

### Frontend
1. Open the frontend folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in the terminal.

### Backend
1. Open the backend folder in a separate terminal.
2. Run `npm install`.
3. Start the server using the command configured in `package.json`.
4. The backend API runs on port 3000.
